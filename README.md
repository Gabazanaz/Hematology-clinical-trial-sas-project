#  Hematology Clinical Trial SAS Project

##  Overview
This project demonstrates analysis of hematology laboratory data using SAS. It simulates a clinical trial setting where patient blood parameters are monitored over time to identify safety signals.

##  Key Features
- Flagging abnormal lab values (LOW / HIGH / NORMAL)
- ADLB dataset creation (Analysis-ready dataset)
- Safety signal detection
- Graphical analysis using PROC SGPLOT
- Integration with Adverse Events (AE)

##  Datasets Used
- Hematology lab dataset (LB)
- Adverse Events dataset (AE)

##  Tools Used
- SAS Studio
 - Clinical data concepts (CDISC-inspired)

##  Skills Demonstrated
- SAS programming (DATA step, PROC IMPORT, PROC SGPLOT)
- Data cleaning and transformation
- Clinical data analysis
- Safety monitoring in clinical trials
  
##  Outputs
- Hemoglobin trend plots
- WBC and Platelet analysis
- Safety signal detection results

##  How to Run
1. Upload datasets into SAS Studio
2. Run sas_program.sas
3. View outputs in Results tab
